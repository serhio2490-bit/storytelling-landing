# Шрифты

Здесь лежат шрифты сайта. Раньше они грузились с Google Fonts — то есть
браузер каждого посетителя ходил на зарубежный сервис и отдавал ему свой
IP-адрес. Теперь файлы свои, обращений к чужим доменам на странице ноль.

| Семейство | Роль | Автор | Лицензия |
| --- | --- | --- | --- |
| Oranienbaum | заголовки | Oleg Pospelov | SIL Open Font License 1.1 |
| Golos Text | основной текст | Paratype | SIL Open Font License 1.1 |
| JetBrains Mono | подписи, номера | JetBrains | SIL Open Font License 1.1 |

Все три под OFL 1.1: их можно свободно использовать, встраивать в сайт и
распространять вместе с ним. Условие одно — рядом лежит текст лицензии,
это `OFL.txt`. Продавать сами шрифты отдельно нельзя.

## Как файлы получены

Субсеты скачаны с Google Fonts, затем подрезаны `pyftsubset` под символы
этой страницы с запасом: вся кириллица, базовая латиница, кавычки-ёлочки,
тире, ₽, №, стрелки. Греческий и вьетнамский выброшены целиком. 342 КБ
исходных субсетов превратились в 200 КБ.

`unicode-range` у каждого файла посчитан по его настоящему набору
символов, а не переписан у Google: в их диапазонах нет ни рубля, ни
стрелки, и эти два знака подхватывались системным шрифтом.

**Если правите тексты на странице — прогоните подрезку заново.** Символ,
которого не было при сборке, уедет в системный шрифт, и увидеть это можно
только глазом. Рецепт — в README проекта, раздел «Шрифты».
