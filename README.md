# Красная нить — лендинг мастерской сторителлинга

Одностраничный сайт без сборки: весь код в `index.html`.
Открывается двойным кликом, ничего устанавливать не нужно.

## Что внутри

- Дуга напряжения истории как визуальная основа страницы: линия рисуется на canvas
  по всей высоте, узлы совпадают с заголовками секций, яркая часть растёт при прокрутке.
- Светлая и тёмная темы, страница подстраивается под настройки системы.
- Шрифты системные (Palatino Linotype + Bahnschrift), ничего не грузится со стороны.

## Что заменить на настоящее

- Тексты, даты и цены — сейчас это образец.
- Отзыв в блоке с цитатой.
- Форма записи демонстрационная: заявка никуда не отправляется.
  На боевом сайте сюда подключается почта или CRM.
